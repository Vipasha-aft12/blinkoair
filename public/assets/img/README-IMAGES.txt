BLINKOAIR — DESTINATION / ROUTE CARD IMAGES
===========================================
Drop a photo into this folder using the EXACT filename below and it appears on
that card automatically. Until a file exists, the card shows its coloured
gradient + skyline as a graceful fallback (nothing looks broken).

SPECS (for fast pages / good Core Web Vitals):
  - Format: .jpg (or convert to .webp and rename the <img> src if you prefer)
  - Size:   ~960 x 600 px, cropped to 16:10, compressed under ~120 KB each
  - License: use only images you are licensed to use. Unsplash.com photos are
    free for commercial use — download the full image, crop, rename, drop here.
